# Zeno: instaladores

Aqui ficam as versões prontas do **Zeno**, o otimizador de PC para jogos (irmão da Kivo).

**Para instalar:** baixe o `Zeno-Setup.exe` da [versão mais nova](https://github.com/adrianoraki/Zeno-releases/releases/latest) e abra.
O Windows pode mostrar "O Windows protegeu o seu PC": clique em **Mais informações › Executar assim mesmo**.
Depois disso o Zeno se atualiza sozinho (Ajustes › Atualizar sozinho).

O código do Zeno fica num repositório privado; este repositório só monta e publica o instalador
(`.github/workflows/lancar.yml`), porque aqui o GitHub Actions é gratuito.
